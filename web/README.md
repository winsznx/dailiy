# Dailiy - Premium On-Chain Journaling SaaS

Dailiy is the definitive on-chain journaling standard for the Web3 ecosystem. This project works to empower developers, traders, and creators to seamlessly document their journeys.

## Features

- **Premium Design**: Minimalist, high-performance UI inspired by Linear and Mercury.
- **Dark Mode**: Fully supported dark/light themes.
- **Responsive**: Mobile-first design.
- **SaaS Pages**: Home, Features, Pricing, About, Blog, and Dashboard.
- **Tech Stack**: Next.js 16 (App Router), Tailwind CSS v4, Lucide React.

## Getting Started

1.  **Install Dependencies**:
    ```bash
    npm install
    ```

2.  **Run Development Server**:
    ```bash
    npm run dev
    ```

3.  **Open in Browser**:
    Visit [http://localhost:3000](http://localhost:3000) to view the application.

## Project Structure

- `app/`: Next.js App Router pages.
- `components/`: Reusable UI components (Navbar, Footer, Button, Card).
- `lib/`: Utilities (cn, etc.).
- `public/`: Static assets.

## Deployment

The project is production-ready. 
Run `npm run build` to generate the production build.
You can deploy this to Vercel, Railway, or any Node.js hosting provider.

## Design System
